# Dragon Telemetry Dashboard

O **Dragon Telemetry** é um painel de controle de missão intuitivo e moderno, desenvolvido para a **Global Solution 2026**. Nosso principal objetivo é monitorar milhares de variáveis críticas de espaçonaves, como a cápsula Dragon, mitigando a fadiga cognitiva dos operadores através de uma hierarquia visual clara e alertas inteligentes.

## Funcionalidades Principais

* **Monitoramento ao Vivo:** Acompanhamento de telemetria em tempo real (LIVE) com recurso de pausa (HOLD) para análise imediata.
* **Prevenção de Falhas e Alertas:** Sistema de avaliação contínua (Normal, Alerta, Crítico) que captura anomalias e as ordena por severidade e recência.
* **Histórico Investigativo:** Tabelas de auditoria contendo as últimas 60 leituras de telemetria com filtros inteligentes de status.
* **Análise de Relatórios:** Geração de estatísticas abrangentes (mínimo, médio e máximo) e gráficos de barra para estudos pós-incidente.
* **Acessibilidade Garantida:** Design inclusivo compatível com o padrão WCAG AA, oferecendo contraste adequado e navegação via teclado.

## Tecnologias a Bordo

Esta Single Page Application (SPA) foi construída com um stack moderno e robusto de desenvolvimento web:

* **React 18:** Criação de componentes de interface de usuário (UI).
* **Vite 8:** Ambiente de desenvolvimento extremamente rápido e build otimizado.
* **Framer Motion 11:** Animações fluidas e de aspecto cinematográfico.
* **Recharts 2:** Gráficos interativos e dinâmicos para dados ao vivo.
